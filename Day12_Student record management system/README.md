# Student Record Management System

Stack: **Java** (JDK's built-in `HttpServer` + JDBC) + **MySQL** (DBMS) + **HTML/CSS/JS** frontend.
No frameworks like Spring or servlet containers (Tomcat) needed — just plain Java.

## Features
- **Students** — add, delete, search by name/roll no/department
- **Courses** — add, delete
- **Marks** — record marks per student per course, auto-computed letter grade (A+ to F), filter by student
- Relational schema: `marks` links `students` and `courses` via foreign keys, with a SQL `JOIN` used to build the marks report

## Folder structure
```
student-record-management-system/
├── schema.sql          # MySQL: students, courses, marks tables + sample data
├── src/
│   └── Main.java        # Entire backend: HTTP server + JDBC + JSON handling
└── public/
    └── index.html        # Frontend UI (tabs: Students / Courses / Marks)
```

## Setup

### 1. Create the database
```bash
mysql -u root -p < schema.sql
```
This creates the `student_records` database with `students`, `courses`, and `marks` tables (foreign-key linked), plus sample rows.

### 2. Download the MySQL JDBC driver
Java needs the MySQL Connector/J jar on its classpath at runtime (not needed to compile). Download it from:
https://dev.mysql.com/downloads/connector/j/

Pick the **Platform Independent** ZIP/TAR, extract it, and copy the `mysql-connector-j-x.x.x.jar` file into your project folder (next to `schema.sql`).

### 3. Configure the backend
Open `src/Main.java` and set your MySQL password near the top:
```java
static final String DB_PASS = "";   // <-- put your MySQL password here
```

### 4. Compile and run
From the project root:
```bash
# Compile
javac -d out src/Main.java

# Run (Linux/Mac)
java -cp out:mysql-connector-j-9.0.0.jar Main

# Run (Windows)
java -cp "out;mysql-connector-j-9.0.0.jar" Main
```
Make sure the `public/` folder (with `index.html`) is in the same directory you run `java` from — it's served as static content.

Open **http://localhost:8080** in your browser.

## API Reference

| Method | Endpoint                     | Description                                 |
|--------|-------------------------------|------------------------------------------------|
| GET    | /api/students                 | List students (supports `?search=`)          |
| POST   | /api/students                 | Add a student                                 |
| PUT    | /api/students/:id             | Update a student                              |
| DELETE | /api/students/:id             | Delete a student                              |
| GET    | /api/courses                  | List courses                                  |
| POST   | /api/courses                  | Add a course                                  |
| DELETE | /api/courses/:id              | Delete a course                               |
| GET    | /api/marks                    | List marks (supports `?student_id=`), joined with student & course names |
| POST   | /api/marks                    | Record a mark for a student in a course       |
| DELETE | /api/marks/:id                | Delete a mark record                          |

## Design notes
- The backend uses only JDK-native classes (`com.sun.net.httpserver.HttpServer`, `java.sql.*`) — no Maven, no Spring, no servlet container. This keeps setup to "download one jar and run."
- JSON is parsed/generated by hand with a small regex-based utility (`Json` inner class) since no external JSON library is used.
- Grades are computed in Java from `marks_obtained`, not stored in the DB — so grading logic can change without a schema migration.

## Notes
- Want this instead as a **Spring Boot** app, or a **Java Swing desktop app** talking directly to MySQL (no HTML at all)? Just ask — the same `schema.sql` works for either.
